# Minidiary · 生活日记小程序

一个基于 **微信原生小程序 + 微信云开发** 的日常生活记录工具：记账、心情随笔、三餐记录、目标打卡、生活日历与小感悟。所有数据保存在云端，仅本人可见。

> 前端：微信小程序原生框架（WXML / WXSS / JS）
> 后端：微信云开发（云数据库 + 云存储），无需自建服务器

---

## 功能特性

| 模块 | 说明 |
|---|---|
| 📒 记账 | 收入/支出、分类、备注、月度预算、按日期筛选明细、每天结余 |
| 💭 随笔 | 心情 emoji、文字、照片（最多 9 张）、地图选点 / 自动定位、按日期查看 |
| 🍜 三餐 | 早/午/晚餐记录、文字与照片（每餐最多 3 张） |
| 🎯 目标 | 每日目标打卡、按日期查看打卡状态 |
| 📅 生活日历 | 月视图标记账目/随笔/三餐/打卡，当天记录按板块分组展示 |
| 💡 小感悟 | 记录简短的体会和经验，支持按日期查看 |
| 👤 我的 | 微信授权登录（兼容新版微信）、编辑头像昵称、本月记录概览 |

---

## 技术栈

- 微信小程序原生框架（WXML / WXSS / JS，ES6+）
- 微信云开发：云数据库（直连读写）、云存储（图片上传/临时链接）
- 微信授权登录（wx.getUserProfile + 匿名降级方案）

## 核心亮点

1. **纯客户端直连云数据库**：无需自建后端与云函数，部署成本低；通过集合权限「仅创建者可读写」实现用户数据隔离（自动按 _openid 过滤）。
2. **图片云存储方案**：随笔/三餐照片上传到云存储，展示时通过临时链接访问，前端封装统一处理。
3. **按日期筛选**：记账、随笔、目标、小感悟均支持按日期查看，数据在本地二次过滤，交互流畅。
4. **生活日历时间线按板块分组**：账目 / 随笔 / 三餐 / 打卡分组展示，而不是按时间混排，信息更清晰。
5. **兼容新版微信登录**：新版微信不再返回真实头像昵称，实现了降级方案（占位资料），保证登录流程永远可用，并支持用户手动编辑昵称/头像。
6. **软删除设计**：目标采用 status: archived 软删除，避免历史打卡记录误删。

## 运行步骤

1. 用 **微信开发者工具** 导入本目录（需要正式 AppID）；
2. 开通 **云开发** 并创建环境；
3. 在 **utils/config.local.js** 填入你的环境 ID（此文件已被 gitignore，不会提交）：
```js
module.exports = { envId: '你的环境ID' }
```
4. 在云开发控制台创建以下集合，权限全部设为 **「仅创建者可读写」**：
expenses / moods / meals / goals / checkins / budgets / users / insights
5. 点击编译即可运行。

> 注：project.config.json 中的 AppID 为占位符，本地运行请用 project.private.config.json（已 gitignore）填写自己的 AppID。
